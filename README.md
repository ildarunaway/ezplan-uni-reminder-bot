**ezplanbot** — telegram-бот который помогает удобно вести список учебных работ, дедлайнов и напоминаний прямо в telegram

## Возможности

- **Предметы:** создание и управление списком учебных дисциплин
- **Работы и дедлайн:** добавление работ по типам, названию и срокам сдачи; поддержка нескольких заданий за один сценарий ввода
- **Быстрый просмотр:** активные и выполненные задачи, просмотр просроченных работ, изменение сроков и редактирование записей
- **Статистика:** обзор задач по предметам и типам, подсчёт выполненных, активных и просроченных работ
- **Умные напоминания:** периодические дайджесты, настройки частоты и времени уведомлений, сообщения о ближайших дедлайнах
- **Сохранность данных:** задания и настройки сохраняются в SQLite между перезапусками приложения при использовании постоянного дискового хранилища



## Быстрый запуск

1. Откройте бота @ezplanbot
2. Нажмите /start
3. Перейдите в раздел «Список предметов»
4. Добавьте свои предметы
5. Выберите предмет и добавьте к нему работы
6. Укажите название работы и дату сдачи в формате ДД.ММ.ГГГГ
7. Настройте напоминания в разделе «Умные напоминания»
